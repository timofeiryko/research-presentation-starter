# Research Presentation Starter — заметки для агента

Стартовый комплект для новых исследовательских задач ТЮБ: метод решения и оформления презентации, собранный по переписке о задаче «Песнь леса» (версия v9, 2026-09-25).

## Что где

- `PROMPT.md` — основная инструкция для решения новой задачи и оформления презентации. Точка входа: передай её агенту вместе с условием задачи.
- `LESSONS_FROM_DIALOGUE.md` — выжимка уроков из правок; правила отсюда имеют приоритет над примером из архива.
- `reference/Presentation.pptx` — редактируемый образец подачи (64 слайда). `reference/SLIDE_MAP.md` — карта слайдов, `reference/REFERENCE_NOTES.md` — границы использования примера.
- `source/build.mjs` — полный скрипт сборки PPTX (Node + `@oai/artifact-tool` из среды Codex; вне этой среды недоступен). Среда и команды: `source/BUILD.md`.
- `source/assets/` — все ассеты. Формулы: `source/assets/formulas/`, источник выражений — `latex.json` (при сборке используются PNG высокого разрешения).
- `MANIFEST.json` — размеры и SHA-256 всех файлов комплекта.

## Правила работы

1. **Целостность.** После распаковки, пересборки или любых манипуляций сверять файлы с `MANIFEST.json` (sha256 + bytes). Расхождений быть не должно.
2. **Пример ≠ шаблон.** Модель из презентации «Песнь леса» — образец объяснения и оформления; без автоматического переноса её модели в новую задачу.
3. **Правки формул.** Редактировать `latex.json` → `node render-formulas.cjs` → `node rasterize-formulas.mjs` (нужны `mathjax-full` и `sharp`), затем пересборка. В PPTX не должно оставаться SVG с невалидными резервными картинками.
4. **Пересборка.** Тексты слайдов и заметок после содержательных правок сверять с готовыми слайдами; финализатор не перезаписывает существующий `output/`.
