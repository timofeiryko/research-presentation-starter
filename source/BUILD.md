# Исходник и пересборка

`build.mjs` — единый исходный скрипт, из которого собрана последняя презентация. Текст, таблицы, графики и схемы создаются редактируемыми объектами. Иллюстрации подключаются из `assets/`. Формулы набраны из LaTeX и встроены как PNG высокого разрешения для совместимости с просмотрщиками. Выражения изменяются через исходный LaTeX и повторный рендер; векторные SVG также включены.

Для редактирования файла `reference/Presentation.pptx` этот скрипт не требуется.

## Среда

Скрипт предназначен для среды Codex с установленным навыком Presentations и библиотекой `@oai/artifact-tool`. В проверенной среде использованы Node.js 24.19.0 и `@oai/artifact-tool` 2.8.76. Библиотека входит в среду Codex; этот комплект не предполагает её доступность через публичный npm.

Не включены `node_modules`, двоичные файлы среды и сам навык Presentations. Их расположение нужно получить в текущей среде через `load_workspace_dependencies`. Затем:

1. Сделай `@oai/artifact-tool` доступным для Node рядом с `build.mjs` штатным способом этой среды.
2. Задай `PRESENTATIONS_SKILL_DIR` — каталог навыка Presentations с `container_tools/artifact_tool_utils.mjs`.
3. Задай `PYTHON_EXECUTABLE` — путь к Python из той же среды.
4. Для финальной проверки импорта задай `RUNTIME_NODE_MODULES` — каталог библиотек среды.

Пути к компьютеру автора в скрипте заменены определением каталога самого файла и переменными окружения. Шрифт Arial должен быть доступен в среде рендера.

## Команды

После настройки среды, из каталога `source`:

```sh
node build.mjs --no-previews
```

Создаёт `.build/candidate.pptx`, карту содержания и файл проверки расчётов.

```sh
node build.mjs --slides=3,8,9,15,17,19,20,21,22,23,26,27,33,34,35,36
```

Дополнительно создаёт изображения выбранных слайдов в `.build/render/`.

```sh
node build.mjs --no-previews --final --name=Rebuilt.pptx
```

Проверяет пакет и записывает `output/Rebuilt.pptx`. Для следующей финальной версии выбери новое имя: финализатор не перезаписывает уже существующий результат. Служебные результаты остаются в `.build/`.

Перед упаковкой этот исходник пересобран из отдельного каталога: 64 слайда, проверка целостности пройдена, замечаний автоматической проверки разметки нет. Текст слайдов и заметок сопоставлен с приложенным PPTX.

Пересборка проверяет геометрию, структуру файла и ряд численных соотношений. Она не подтверждает научную истинность гипотезы. После содержательных правок необходимо посмотреть готовые слайды и проверить причинные связи.

## Что менять для новой задачи

Используй `PROMPT.md` для новой концепции. В скрипте можно сохранить размеры, палитру, функции текста, таблиц, изображений и последовательностей. Тексты, ссылки, модели, расчёты и исходные шпаргалки относятся к «Песни леса» и должны быть заменены материалами новой задачи.

Необязательно использовать этот же программный инструмент: PPTX и Markdown остаются самостоятельными материалами комплекта.

## Формулы LaTeX

Для обычной пересборки презентации MathJax не требуется: готовые PNG, SVG и их размеры уже включены в `assets/formulas/`. Для изменения формул отредактируй `assets/formulas/latex.json`, установи `mathjax-full@3.2.2` рядом со скриптом и выполни:

```sh
npm install --no-audit --no-fund mathjax-full@3.2.2
node render-formulas.cjs
node rasterize-formulas.mjs
node build.mjs --no-previews
```

Первый скрипт обновляет SVG и `index.json`, сохраняя исходный LaTeX. Второй через библиотеку `sharp` из среды создаёт PNG при 384 dpi. Презентация использует PNG: внутри PPTX не должно оставаться SVG с невалидными резервными картинками. После правок посмотри слайды: размер дробей и корней влияет на размещение.
